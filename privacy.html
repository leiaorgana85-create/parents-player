Parents Player Privacy Policy

Last updated: October 22, 2026

Google Drive access

Parents Player reads the configured public-link Google Drive PLAYLIST folder through the Google Drive API using a restricted browser API key. The restricted key is supplied automatically by an owner-run Google Apps Script configuration service, or may be entered manually in Settings. The app does not request Google account sign-in or OAuth access.

How Drive data is used

Drive file metadata and audio bytes are used only to build the local audio library and support offline playback. Parents Player does not upload, modify, or delete Google Drive files.

Storage

Downloaded audio, library metadata, playback state, folder configuration, and the restricted Google Drive API key may be stored locally in the browser or installed web app on the user's device. Parents Player does not store a Google password, OAuth token, or OAuth client secret.

Sharing and sale

Parents Player does not sell user data and does not use data for advertising. The app communicates with Google services only for connection setup, playback and offline downloads as described above.

Retention and deletion

Device-local audio and app data remain on the device until removed through the app's storage controls, browser controls, or app reset. Removing local data does not delete the Google Drive master files.
